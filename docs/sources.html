Where every NoiseFile rule comes from.

NoiseFile is made by WiM Labs, a small company. It is not part of any city or government. Every rule the app shows is quoted from the public code or official page of that city. The 159 sources below cover all 36 cities. Catalog version 2026-09-30.2.
