# How to Install NoiseFile (Side-loading Guide)

Because NoiseFile is currently distributed directly via GitHub instead of the Google Play Store, you will need to "side-load" the app onto your Android device.

## Step 1: Uninstall any older versions
If you already have a previous version of NoiseFile on your phone, **you must delete it first**. 
Android security blocks updates if the background developer signatures do not match perfectly, which happens frequently with cloud-built test versions.
1. Find the NoiseFile app icon on your home screen or app drawer.
2. Long-press the icon.
3. Tap **Uninstall**.

## Step 2: Download the APK
1. Go to the main NoiseFile GitHub page on your Android phone's web browser.
2. Tap the large **"⬇️ DOWNLOAD NOISEFILE APK"** link in the README.
3. Wait for the `00-NOISEFILE-DOWNLOAD.apk` file to finish downloading.

## Step 3: Install the App
1. Tap the downloaded file in your browser's "Downloads" popup, or open your phone's "Files" app and go to the Downloads folder to tap it.
2. If your phone asks for permission to **"Install unknown apps"** from your browser or file manager:
   - Tap **Settings** on the prompt.
   - Toggle the switch to **Allow from this source**.
   - Hit the back button.
3. Tap **Install** on the NoiseFile installation screen.
4. Tap **Open** to launch the app!

## First Launch Experience
NoiseFile is **100% local-first**. 
- There are **no accounts**, **no passwords**, and **no sign-ins**.
- All incident data stays directly on your phone.
- The only popup you will see is an Android prompt asking for **Microphone Permission**. You must grant this so the app can measure decibel levels!
